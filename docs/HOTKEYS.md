# uAudio hotkeys / Горячие клавиши

## RU
- Ctrl+N — новый проект
- Ctrl+O — открыть
- Ctrl+S — сохранить
- Ctrl+Shift+S — сохранить как
- Ctrl+E — экспорт WAV
- Ctrl+Z — отменить
- Ctrl+T — добавить дорожку
- Space — play/pause
- Esc — стоп
- Ctrl+X — вырезать выделение
- Ctrl+Shift+X — обрезать вне выделения
- Ctrl++ / Ctrl+- / Ctrl+0 — зум
- F1 — памятка
