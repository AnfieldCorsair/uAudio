# uAudio hotkeys / Горячие клавиши

## RU
- Ctrl+N — новый проект
- Ctrl+O — открыть проект или аудиофайлы
- Ctrl+I — импортировать аудиофайлы
- Ctrl+S — сохранить
- Ctrl+Shift+S — сохранить как
- Ctrl+E — экспорт WAV
- Ctrl+Z — отменить
- Ctrl+T — добавить дорожку
- Space — play/pause
- Esc — стоп
- Ctrl+X — вырезать выделение
- Ctrl+Shift+X — обрезать вне выделения
- Ctrl++ / Ctrl+- / Ctrl+0 — зум
- Drag & Drop — перетаскивание файлов/папок из Проводника (с выбором дорожки или созданием новой дорожки для каждого звука)
- F1 — памятка

## EN
- Ctrl+N — new project
- Ctrl+O — open project or audio files
- Ctrl+I — import audio files
- Ctrl+S — save
- Ctrl+Shift+S — save as
- Ctrl+E — export WAV
- Ctrl+Z — undo
- Ctrl+T — add track
- Space — play/pause
- Esc — stop
- Ctrl+X — cut selection
- Ctrl+Shift+X — trim outside selection
- Ctrl++ / Ctrl+- / Ctrl+0 — zoom
- Drag & Drop — drag audio files/folders from Explorer (choose target track or create a new track per file)
- F1 — shortcuts
